# 分步故障排查与实物记录

## 故障表

任何异常发热、焦味、反复电源保护、舵机持续顶住限位：先切断三个低压电源，保留照片后检查。不在带电状态拔插 FFC、改跳帽或交换舵机三芯线。

| 现象 | 第一步 | 第二步 | 仍失败时交给工程侧的证据 |
|---|---|---|---|
| NUCLEO 接 PC 能跑、接充电器不跑 | 检查目标供电 LD3 和板级日志，不只看 ST-LINK 灯 | 核对 MB1136 修订、JP5 U5V 与 JP1 模式；记录 USB 电流是否满足手册路径 | 跳帽照片、供电方式、USB 电压电流；决定是否改 E5V 模式 |
| PC 找不到 ST-LINK/串口 | 确认 USB-A→Mini-B **数据线**，更换直连 USB 口 | 检查 CN2 跳帽、系统设备列表，不切割板卡 | 设备管理器/工具探测输出、板号照片 |
| P4 反复重启/相机一开就掉线 | 去掉舵机支路，P4 独立测试 | 看启动复位原因，检查 5 V 电源与 USB 线压降 | 完整启动日志、USB 表读数、是否只在摄像开启时发生 |
| 无摄像头/黑屏/花屏 | 断电检查是否插 CSI 而非 DSI | 对照照片检查 FFC 触点面、平直度、锁扣及相机型号 | 摄像头正反面、两端插座照片、识别/采集日志 |
| 两板 UART 无回应 | 全断电复核 PA9→GPIO21、GPIO20→PA10、GND | 核对 CN10 与 P1，确认不是相邻 P2；检查 115200 8N1、固件版本 | 最终线图照片、收发计数/CRC 错误，不能随机换成 GPIO4/5 |
| 固件返回运动错误 5/disabled | 确认当前是否输出禁用参考固件 | 查看硬件是否已经达到允许运动的条件 | 交付包版本；由工程侧创建允许输出的受限构建，不绕过保护 |
| 舵机完全不动 | 切电核对三线顺序和独立电源 | 查看命令是否 ACK、是否收到心跳，以及该批是否支持 3.3 V PWM | 命令/回应日志、接头照片、电压；区分线序、供电、门限与软件 |
| 舵机抖动、转动时重启 | 立刻停止，解除负载/FFC 拉力 | 分别测试单轴；确认负载电流没过面包板/MCU，检查压降 | 单轴/双轴区别、机械位置视频、USB 表记录；必要时核对预装缓冲模块 |
| 点击角度但实际方向相反 | 暂停并回到已核验中位附近 | 用±5°测试确认哪个轴/符号反向 | 工程侧调整映射，保存新限位配置，不让用户改变齿轮或硬扭舵机 |
| 回同一观察点识别忽好忽坏 | 保留所有失败截图与当时角度/光照 | 排除齿隙、固定松动、FFC 拉扯和反光，再调 ROI | 50 次往返图像、失败样本、装配照片；误差不得被“算法成功率”掩盖 |
| 局域网有视频，手机流量没有 | 先确认手机确实关闭 Wi-Fi | 检查登录、设备在线、WHEP/ICE/TURN/HTTPS 日志；不要开放无认证摄像头端口 | 两端网络/手机系统、浏览器、连接日志；按软件指南修复公网路径 |
| 手机找不到蓝牙 | 确认手机蓝牙和权限、距离、配对窗口 | 检查使用支持的浏览器/客户端；iOS Safari 不当作 Web Bluetooth 已支持 | 设备型号/OS/浏览器、BLE 广播与连接日志；无线硬件存在不代表应用已实现 |
| 装壳后 Wi-Fi/BLE 变差 | 对比开壳与闭壳，保持同一位置 | 检查 C6 天线附近金属、线团、螺钉及电源噪声 | 信号/断流对比与照片；修改布局，不能仅靠提高发射参数掩盖 |

## 实物验收记录模板

每条记录保存日期、操作者、板卡身份、固件 SHA-256、软件版本、网络和原始文件路径。失败结果也保留。没有实测时写 `未测试`，不能填预计值冒充结果。

| 测试 ID | 方法与样本 | 记录指标 | 初始状态 |
|---|---|---|---|
| HW-01 | 无外设检查两板分别独立上电；再接 UART | 枚举/复位原因/日志，供电模式与接线照片 | 未测试 |
| HW-02 | 三路供电空载、单轴、双轴、开摄像分别观察 | 电压、电流、复位次数、异常温升；标注 USB 表分辨率局限 | 未测试 |
| HW-03 | 单轴中位±5°到最终收紧后的窗口 | 实际方向、可用脉宽、机械/FFC 最小间隙，停止条件 | 未测试 |
| HW-04 | 2–3 预置点往返至少 50 次 | 目标 ROI 中心偏差/像素或归一化坐标；稳定等待时间；失败次数 | 未测试 |
| HW-05 | 单点、定时巡检、事件复核三策略，对同一状态改变过程 | 检出时间、漏检/误报、不确定率、每小时动作数；明确共同样本 | 未测试 |
| HW-06 | 3 种受控光照、总计至少 100 个有真实标签样本 | 混淆矩阵、各状态样本量、不确定样本独立统计；保存原图 | 未测试 |
| HW-07 | 断网、断服务器连接、一次正常重启后恢复 | 舵机停止/恢复过程、旧命令拒绝、日志连续性；不能自动重放运动 | 未测试 |
| HW-08 | 手机蜂窝网络看 10 分钟并操作两个点；PC 在另一网络重复 | 分辨率、实际帧率、延迟测法、断流次数、码率和流量 | 未测试 |
| HW-09 | Android/PC 目标平台近场 BLE 查询、控制、重新连接 | 平台、浏览器、权限、认证窗口、成功/失败时间；Wi-Fi 凭据不进日志 | 未测试 |
| HW-10 | 装壳后无 PC 独立运行至少 2 小时 | 重启、事件丢失、外壳温升、摄像稳定性、线缆受力照片 | 未测试 |

## 论文材料的使用方式

可以立即使用：架构、模块选型理由、候选电源树、信号分层、协议机制、CAD 设计方法、真实构建和主机测试证据。

必须后补：最终实物接线照、采购发票/实付成本、实际供电与波形、视频延迟/帧率、ROI 重定位误差、识别混淆矩阵、蓝牙/两地网络兼容性、装壳连续运行。

数据记录建议 CSV 字段：`test_id,run_id,timestamp,device_id,firmware_sha256,preset_id,light_condition,ground_truth,predicted_state,confidence,uncertain,latency_ms,voltage_v,current_a,source_file,result,notes`。不把指令角度当测得角度，不把主机模拟事件当实物事件，不把网页报价当最终成本。
