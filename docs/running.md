# 运行与部署边界

## 本地模拟

在 `software/server` 完成npm依赖安装后运行 `npm run dev`。每次启动生成随机登录口令和设备令牌；终端只供自己查看，真实配置与历史数据不进入公共仓库。模拟器只验证状态、命令和来源标记，没有真实摄像头视频。

如果已有服务占用默认端口，可以在自己的终端设置 `PORT` 为其他可用端口后启动。不要结束不属于本任务的服务。

## 真实设备配置

`npm run configure` 会交互生成被忽略的 `config.local.json`，拒绝覆盖已有文件。只有准备接入自己的真实设备时才使用；不要把设备令牌、Wi-Fi、媒体凭据或配置提交到仓库。本次迁移未执行该配置或连接真实设备。

部署到公网需要选定常开服务器、HTTPS域名、会话/设备/媒体凭据与媒体服务；Pages只能承载静态内容。生产配置的HTTPS、cookie、来源与媒体条件由服务检查，不能把开发模式直接暴露到公网。

## 视频与蓝牙

真实视频需要配置WHIP/WHEP媒体服务和硬件发布端。源码保留媒体代理与客户端，但MediaMTX、Caddy、FFmpeg、ESP-IDF及其依赖不作为本项目自有二进制发布。未在此次公开副本重新进行完整视频媒体闭环或真实网络/硬件测试。

蓝牙依赖浏览器Web Bluetooth；Android Chrome和PC Chrome/Edge是设计目标，不能概括为所有手机支持。iOS Safari入口未在当前项目实现。

## 模型和电路

自有STEP/STL/FreeCAD源可直接用相应查看器打开；参数重生成还依赖源码中的Python CAD工作流。模块互连图和有限角度约束应结合到货板卡/线束/负载核实，仿真、导入、构建或模型相交检查不等于实板通过。
