04 / TRY LOCALLY

不接硬件，也能试软件流程。

安装Node.js 24+，获取源码后在自己的终端执行。启动时会显示本次随机登录口令；模拟器没有现场视频。

git clone https://github.com/yangwei251003/active-inspection.git
cd active-inspection/software/server
npm ci --ignore-scripts
npm run dev

云端完整服务需要另行部署Node与媒体服务。本页是GitHub Pages静态预览，未把静态页面说成后端已在线。
